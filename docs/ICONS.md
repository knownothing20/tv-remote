# 图标设计规范

「马卡龙小电视」：一个 Retro 造型的小电视，用马卡龙色系表达"可爱但不幼稚"。
**核心规则：两态机身完全一致，只改变屏幕。**

## 双态

| 状态 | 屏幕 | 说明 |
|---|---|---|
| 未连接 | `#232830` 纯黑 + 5% / 3.5% 两道斜向玻璃反射 + 深色内描边 | 像关掉的电视，玻璃仍有质感 |
| 已连接 | `#F1FDFF` 奶白底 + `#A6DFFF` 天蓝光带 + 白色高光条 + 16% / 10% 反射 | 像亮起的屏幕，有辉光错觉 |

## 配色

| 用途 | 色值 |
|---|---|
| 机身主色 | `#A9E5CB` |
| 机身上沿（受光） | `#C4F1DD` |
| 机身下沿（暗带） | `#8FD3B2` |
| 内圈釉光 | `#E8FFF5` |
| 描边 | `#6FC2A0` |
| 屏幕边框 | `#F7FFFC` |
| 边框内凹（上暗 / 下亮） | `#DFF2E9` / `#FFFFFF` |
| 天线 / 支架 | `#6BBF9B` / `#93D8B7` |
| 天线糖球 | `#FFB7C9`（草莓）/ `#FFDD97`（奶油） |

## 质感层次（由下到上）

1. 支架（底部亮边 3.5px）
2. 天线（4.5px 圆头线）+ 糖球 + 左上 1.9px 白色高光点
3. 机身圆角矩形（半径 20/160）
4. 上沿 16px 亮带、下沿 26px 暗带（裁剪进机身）
5. 内圈 1.2px 淡光描边
6. 机身描边 2.5px
7. 屏幕边框（半径 12）+ 顶部内阴影 + 底部亮边 → 内凹感
8. 屏幕（半径 8）+ 状态填充 + 玻璃反射
9. 状态高光（亮屏时：白色横条 + 白色内描边）

坐标以 160×150 为单位正方形绘制，再按 1024px 渲染后降采样，保证任意尺寸都清晰。

## 尺寸

导出 9 档：16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256。

- 32px：天线、指示灯、边框仍可辨
- 24px：细节开始融合，屏幕明暗对比仍成立
- 16px：只剩"圆角机身 + 屏幕块"，但黑/亮对比清晰 —— 托盘图标的最低可读要求

## 重新生成

python scripts/gen_icons.py            # 输出到 assets/icons 与 assets/preview
