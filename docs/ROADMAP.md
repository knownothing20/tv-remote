# 版本规划

## 版本策略

遵循 [语义化版本 2.0](https://semver.org/lang/zh-CN/)：`MAJOR.MINOR.PATCH`

| 位 | 触发条件 | 例子 |
|---|---|---|
| MAJOR | 破坏性变更：配置格式、API 路径、打包方式、最低 Python 版本 | 1.x → 2.0 |
| MINOR | 向后兼容的新功能 | 1.0 → 1.1 |
| PATCH | 修复、文案、样式、依赖升级 | 1.0.0 → 1.0.1 |

- **预发布**：`v1.1.0-beta.1`，发布为 GitHub Pre-release
- **分支**：`main` 保持可发布；功能走 `feat/<slug>`；发布走 `release/<version>`
- **发布流程**：更新 `src/tvremote/__init__.py` 的 `__version__` 与 `CHANGELOG.md` → 提交 → 打 tag `vX.Y.Z` → 推送
- **CI**：`.github/workflows/build.yml` 在 tag 推送时自动构建 `TrayTVAdmin.exe` 并挂到 Release
- **产物**：源码包（自动）+ Windows 单文件 exe（CI 构建）

## 已发布

### v1.0.0 · 2026-11-13

首个公开版本：

- 托盘单文件应用（菜单：打开面板 / 复制地址 / 重启服务 / 退出即停服务）
- 双态图标：黑屏=未连接、亮屏=已连接，5 秒轮询
- 面板：硬件、内存、存储、网络、前台应用、进程 Top、后台服务、自启动清单、省电白名单
- MJPEG 实时画面（约 1 fps，单路）
- 快捷操作：打开投屏 App / 回桌面 / 返回键 / 加白名单 / 保存截图
- 配置与设置落在 `local/`，隐私脱敏默认开启
- 模块化源码、图标生成器、一键打包脚本、GitHub Actions

## 路线图

### v1.1.0 · 多设备管理

- `local/devices.json` 支持多台电视
- 托盘菜单与面板顶部切换设备
- 每台设备独立状态缓存与轮询

### v1.2.0 · 应用管理

- 已安装应用列表（包名、版本、大小、是否系统应用）
- 卸载 / 停用 / 清除数据（调用系统安装器，需用户确认）
- 自启动项开关（对 OEM 定制系统标注风险提示）

### v1.3.0 · 更新检查

- 启动时查询 GitHub Releases 最新版本，仅在设置开启时执行
- 只提示、不自动下载（开源项目更可控）
- 面板显示「有新版本」入口

### v1.4.0 · 局域网访问

- 可选监听 `0.0.0.0`，带访问口令（默认关闭）
- 手机 / iPad 直接打开面板（PWA manifest，可添加到主屏）
- 明确安全提示：仅在可信局域网开启

### v2.0.0 · 插件化与跨平台

- 采集器插件化：每类信息一个 provider（硬件 / 网络 / 应用 / 自启）
- macOS 与 Linux 托盘（`pystray` 已支持，需补平台适配）
- 评估更轻的壳层（如 Tauri）以减小体积

## 明确不做

- 绕过厂商的安装校验 / 破解类功能
- 任何形式的数据上传（全部数据留在本地）
- 内建自动更新（仅提示，由用户决定）
